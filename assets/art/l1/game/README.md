# L1 汉字游戏素材

这组素材用于 Phaser / H5 游戏场景，不用于信息图或页面 UI。

## 核心原则

每个汉字采用：

**汉字本体 → 对应象形物体 → 可交互游戏对象**

例如：

- `山`：大字形 + 三峰山体，可用于登山、找山、山峰配对、字形变形
- `水`：大字形 + 流水/水滴，可用于引水、接水、钓鱼、找水
- `木`：大字形 + 树木，可用于种树、砍伐/搭桥、树木配对
- `日`：大字形 + 太阳，可用于太阳升起、找太阳、昼夜切换

## 使用规则

1. 游戏场景里，目标汉字应作为第一视觉元素之一，不能缩成角落标签。
2. 象形物体必须与汉字的语义直接对应。
3. 不在生图中放题目、按钮、说明文字；UI 文本由 React 渲染。
4. 游戏引擎可以把汉字、对象、背景拆成独立节点进行动画。
5. 后续扩展 3000 字时，保持相同命名规则：`char-{pinyin}-game.svg`。
