# Bunny 进阶与等级体系

## 1. 设计目标

Bunny 不采用单一“经验值等级”。等级用于表达孩子的总体学习阶段，但真正的学习决策基于多维能力模型。

四层模型：

```text
课程阶段 Grade Stage
        ↓
成长等级 Bunny Level
        ↓
能力雷达 Ability Profile
        ↓
汉字/词语/阅读的细粒度掌握度 Mastery
```

核心原则：

- 等级体现成长，不直接等于成绩。
- 人教版 1～2 年级是课程底座，不是唯一进阶条件。
- 识字量、朗读、理解、表达、书写分别记录。
- 新内容应略高于当前能力，避免过难或重复刷已掌握内容。
- 晋级主要依据稳定表现，而不是一次答对。

## 2. Bunny 成长等级

第一版建议 10 个等级，后续可扩展至 20 级。

| Level | 名称 | 典型能力 | 解锁 |
|---|---|---|---|
| Lv1 | 汉字小芽 | 认识图、声音、基础字形 | 图卡、短互动 |
| Lv2 | 汉字小苗 | 稳定识别高频字 | 简单绘本 |
| Lv3 | 识字小兔 | 字 → 词 | 词语游戏、同步绘本 |
| Lv4 | 阅读小芽 | 词 → 简单句 | 跟读、句子任务 |
| Lv5 | 阅读小手 | 连续阅读短句 | 自己读、角色对读 |
| Lv6 | 故事探险家 | 理解短故事 | 阅读寻宝、剧情任务 |
| Lv7 | 汉字探案家 | 偏旁、字族、字源规律 | 汉字探秘局 |
| Lv8 | 阅读大玩家 | 句群/短段理解 | 二年级进阶内容 |
| Lv9 | 故事表达家 | 复述、看图表达 | AI 表达任务 |
| Lv10 | 阅读大师 | 独立完成分级阅读 | 高阶绘本、开放表达 |

等级不是按年龄强制锁死；系统根据能力模型推荐适合内容。

## 3. 四条独立能力线

### 3.1 识字能力

```text
图形识别 → 听音认字 → 字形识别 → 词语识别 → 句中识字 → 灵活调用
```

### 3.2 阅读能力

```text
听故事 → 跟读 → 自己读词 → 自己读句 → 连续阅读 → 段落理解 → 主旨/细节
```

### 3.3 表达能力

```text
跟说 → 看图说词 → 看图说句 → 复述故事 → 回答为什么 → 开放表达
```

### 3.4 书写能力

```text
认字 → 笔画 → 笔顺 → 描红 → 临写 → 独立书写
```

## 4. 汉字 Mastery 五级

每个汉字独立维护掌握度，不因“学过一次”直接变为已掌握。

| Level | 状态 | 判定示例 |
|---|---|---|
| M0 | 未接触 | 未学习 |
| M1 | 见过 | 能在少量干扰中找到 |
| M2 | 认识 | 图/音/字匹配稳定 |
| M3 | 理解 | 能识别词义和基本用法 |
| M4 | 应用 | 能在绘本句子中正确识别 |
| M5 | 稳定掌握 | 多场景、间隔复习后仍稳定 |

## 5. 单字进阶路径

例如“森”：

```text
第一次：看森林图片 → 森
第二次：听“sēn” → 找森
第三次：认识“森”由多个“木”组成
第四次：词语“森林”
第五次：绘本“小兔子在森林里……”
第六次：孩子跟读
第七次：自己读
第八次：小游戏识别
第九次：复习
第十次：新绘本中迁移使用
```

只有在跨场景表现稳定后才进入 M5。

## 6. 进阶规则

推荐分数模型：

```text
mastery =
  recognition * 0.25 +
  listening   * 0.15 +
  vocabulary * 0.15 +
  reading    * 0.20 +
  context    * 0.15 +
  retention  * 0.10
```

阈值示例：

- < 40：继续引导，不增加难度。
- 40～60：增加重复曝光。
- 60～80：进入混合练习。
- 80～90：允许进入更复杂绘本。
- > 90 且间隔复习稳定：标记“稳定掌握”。

以上权重必须通过真实数据校准，不作为教育测量的绝对标准。

## 7. Pad 首页上的成长表达

首页不显示“考试分数”，而显示：

```text
Lv.6 故事探险家
已掌握 186 个汉字
连续学习 7 天
本周读了 6 本绘本
下一目标：200 字
```

让孩子看到“我要去哪里”，而不是“我考了多少分”。

## 8. 解锁机制

### 内容解锁

- 绘本：达到推荐阅读门槛即可解锁。
- 游戏：根据当前弱项动态出现。
- 汉字探秘：优先展示近期新字和高价值字。
- 高阶内容：满足多个能力维度后开放。

### 不采用的机制

- 不能用失败次数锁死内容。
- 不能强迫孩子按固定顺序刷题。
- 不用排行榜制造同龄竞争。
- 不用“连续答题越多越好”诱导过度使用。

## 9. AI 个性化路径

每天 AI 生成一个 15～20 分钟学习计划：

```text
1. 2 分钟：热身复习 3～5 个弱字
2. 5 分钟：绘本陪读
3. 3 分钟：新字故事 + 游戏
4. 3 分钟：孩子自己读
5. 2 分钟：理解/表达任务
6. 1～2 分钟：间隔复习 + 奖励
```

孩子状态变化后，后续计划自动调整。

## 10. 年级与等级关系

不强制“一年级 = Lv1～Lv5”。推荐以课程阶段作为内容边界，以等级作为能力表现。

```text
一年级上：重点完成 M0→M3，并建立听读习惯
一年级下：重点完成字词→句子→自主跟读
二年级上：重点进入句群、短段和故事理解
二年级下：重点进入复述、表达、阅读策略
```

## 11. 家长视图

家长看到的是能力变化：

- 识字量
- 稳定掌握字量
- 绘本阅读量
- 跟读次数
- 阅读时长
- 朗读表现趋势
- 理解表现趋势
- 最近薄弱字/词
- 推荐亲子阅读内容

不要只展示“游戏玩了多久”。
