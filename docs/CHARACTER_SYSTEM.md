# Bunny 汉字学习体系

## 1. 目标

让孩子不仅“认得字”，而是逐步完成：

```text
见字 -> 听音 -> 认形 -> 懂义 -> 组词 -> 读句 -> 在故事中使用 -> 自己朗读 -> 长期记忆
```

## 2. 汉字能力状态

每个汉字维护独立 mastery profile：

```text
UNKNOWN
  -> EXPOSED
  -> HEARD
  -> RECOGNIZED
  -> UNDERSTOOD
  -> USED
  -> READ
  -> WRITTEN
  -> MASTERED
```

状态并非只能单向变化。遗忘后可以回落到 learning/review 状态。

## 4. 汉字故事

### 4.1 设计原则

汉字字源内容必须区分：

- 可考证的文字学事实
- 面向儿童的简化解释
- 为了故事性而创作的拟人化场景

不能把创作故事伪装成真实历史。

### 4.2 四类儿童化呈现

#### 象形字

```text
真实事物
  -> 古人画图
  -> 早期字形
  -> 今天汉字
```

适合：日、月、山、水、火、木、口、目、马、鸟等。

#### 会意字

展示部件组合后产生的新意义，例如把“人依树”作为“休”的儿童化解释，同时在内容元数据中保留文字学说明和可信等级。

#### 形声字

通过“汉字家族”建立偏旁和声旁的关系，例如：

```text
青
├── 清
├── 晴
├── 请
└── 情
```

必须说明：不是所有现代同偏旁字都完全满足简单的儿童化规则。

#### 词语/成语典故

通过短故事解释词语在真实语言中的用法。

## 5. 汉字时光机

每个支持演变展示的汉字可提供：

```text
古代字形
  -> 中间字体阶段
  -> 楷书
  -> 今天的字
```

每一步最多 1-2 句解释，避免给低龄儿童增加专业负担。

## 6. 汉字博物馆

孩子掌握一个字后，可解锁：

- 字卡
- 语音
- 字源故事
- 词语
- 例句
- 相关绘本
- 相关游戏
- 汉字家族

博物馆是长期收集系统，不替代课程主流程。

## 7. 生字教学策略

一次互动尽量只突出一个明确目标。

例如学习“森”：

1. 先观察森林场景
2. 看“森”字
3. 听“sēn”
4. 讲“很多树在一起”的儿童化概念
5. 点选“森”
6. 在绘本句子中再次出现
7. 跟读
8. 游戏巩固

## 8. 写字

写字功能分为：

- 看笔画
- 看笔顺
- 描红
- 临写
- 自主书写

一年级优先保证认字、观察字形和正确笔顺；随着能力提升逐步增加书写要求。

## 9. 复习

每个汉字记录：

- 最后接触时间
- 最后正确时间
- 连续正确次数
- 最近错误类型
- 语境错误次数
- 朗读表现
- 复习优先级

复习不是单独刷卡，而优先在下一本绘本、故事或小游戏中自然复现。
