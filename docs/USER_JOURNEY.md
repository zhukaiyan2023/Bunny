# Bunny 典型用户旅程与产品状态

## 1. 第一次进入

孩子看到 Bunny：

> “小兔子今天要去一个神奇的地方，你要一起去吗？”

不先展示课程表，不先展示考试分数。

## 2. 今日冒险

```text
今日冒险

🐰 帮小兔找到家
📖 推荐故事：小兔找妈妈
🔤 今日新字：森、家、找
🎮 可玩：森林寻宝
```

## 3. 故事阶段

### 第一遍

Bunny 讲故事。

### 第二遍

Bunny 和孩子一起读。

### 第三遍

孩子自己读关键句。

## 4. 遇到生字

孩子点击“森”：

```text
森
sēn
🌲🌲🌲
很多树在一起

[听一听]
[我来读]
[看看它的来历]
```

返回原故事后继续。

## 5. 游戏阶段

故事中的任务转化为游戏：

```text
找不到妈妈
 -> 找到“家”
 -> 找字游戏
 -> 解锁地图
 -> 故事继续
```

## 6. 结束阶段

不要只显示“得分 95”。

显示：

```text
🎉 今天完成冒险！

学会了 3 个字
📖 读完 1 本故事
🎤 自己读了 4 句话
🌳 森林地图 +1 区域
🏛️ 汉字博物馆 +3 收藏
```

## 7. 下一次进入

Bunny 不重复上一天完整内容，而是：

```text
复习 1-2 个薄弱字
+
一个新的故事
+
一个新的探索任务
```

## 8. 家长视图

家长端核心不是孩子排名，而是：

- 本周阅读时间
- 完成绘本数量
- 新掌握汉字
- 最需要复习的字
- 跟读次数
- 独立阅读情况
- 推荐下一步

## 9. 无压力设计

孩子可以：

- 跳过某个游戏
- 重听故事
- 重读句子
- 返回汉字博物馆
- 自由探索世界

但核心课程路径仍然有清晰推荐，不让“自由探索”破坏学习目标。
