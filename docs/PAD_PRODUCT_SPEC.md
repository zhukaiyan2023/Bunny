# Bunny Pad 学习机产品与交互规格

## 1. 设备定位

Bunny 目标设备优先为 8～13 英寸横屏 Pad/学习机，儿童双手触控，距离约 35～55cm；手机只作为兼容入口，不作为主交互设计标准。

核心原则：

1. 大卡片、大字号、大触控区。
2. 一个页面一个主要行动，不让儿童找按钮。
3. 关键内容在中央视区完成，辅助功能在边缘。
4. 语音优先、触控优先，键盘输入为辅。
5. 家长入口必须和儿童入口明显隔离。
6. 单次学习 15～20 分钟，页面之间尽量无复杂表单。

## 2. Pad 页面布局

```text
┌───────────────────────────────────────────────────────────┐
│ 顶栏：Bunny / 返回 / 页面标题 / 家长入口                 │
├──────────┬───────────────────────────────────┬────────────┤
│          │                                   │            │
│ 纵向导航 │          主要学习视区              │ 上下文工具 │
│ 80~100px  │          约 65~75% 屏幕            │ 120~180px  │
│          │                                   │            │
├──────────┴───────────────────────────────────┴────────────┤
│ 底部：当前任务 / 进度 / 下一步 / 语音控制                 │
└───────────────────────────────────────────────────────────┘
```

绘本阅读时，尽量隐藏非必要导航；游戏时，保持任务、反馈和角色在视觉中心。

## 3. 首页：Bunny 世界地图

首页不是“课程列表”，而是儿童的长期成长地图。

核心区：

- Bunny 角色
- 当前等级
- 当前连续学习天数
- 当前主线世界
- 今日任务
- 下一进阶目标

世界入口：

- 故事王国：绘本与教材同步阅读
- 汉字博物馆：字源、字形、汉字家族
- 冒险乐园：识字和语文游戏
- 汉字探秘局：偏旁、组词、推理、字源任务

## 4. 首页成长信息

儿童端展示：

```text
Lv.6 故事探险家
已掌握 186 字
连续学习 7 天
今日目标 12 分钟
下一目标 200 字
```

不要展示复杂百分比排行榜；用“距离下一个目标还有多少”强化成长感。

## 5. 绘本陪读页

### 5.1 主视觉

插画占上半区；文字位于插画下方或安全区；正文至少 32px，重点词 36～42px。

### 5.2 四种阅读模式

- Bunny 讲：AI/预制语音完整讲故事。
- 一起读：Bunny 一句，孩子一句。
- 我自己读：孩子独立朗读并获得鼓励式反馈。
- 角色对读：孩子扮演角色与 Bunny 对话。

### 5.3 文字交互

点击字/词：弹出轻量卡片，不离开绘本。

卡片包含：

- 读音
- 简单释义
- 配图
- 字源入口
- 常用词
- “回到故事”按钮

### 5.4 陪读状态

```text
未开始
 → Bunny示范
 → 等待孩子
 → 识别中
 → 正确/需再读
 → 自动继续
```

失败不能阻塞故事；允许“跳过并稍后复习”。

## 6. 汉字详情页

建议采用 Pad 横屏双栏：

```text
左：大字 / 动画 / 书写
右：字源故事 / 演变 / 词语 / 绘本用例
```

顶部显示：

- 汉字
- 拼音
- 已掌握等级 M0～M5
- 收藏
- 播放

中部 Tab：

- 字源故事
- 字形演变
- 生活中的字
- 相关词语
- 我读过的绘本

## 7. 汉字故事交互

字源故事必须儿童化、短时长。

```text
看真实对象
 → 古人怎么画
 → 字形怎么变化
 → 今天为什么这样写
 → 孩子复述/选择
```

一个故事 20～60 秒为宜；需要更长解释时拆成多个互动镜头。

## 8. 游戏页

游戏一屏只保留一个任务：

```text
任务
 ↓
操作
 ↓
即时反馈
 ↓
奖励
 ↓
下一任务
```

推荐触控热区：不小于 72×72 CSS px；关键按钮建议 88～120px 视觉尺寸，具体根据实际 DPI 与设备分辨率校准。

游戏类型随等级增加：

### Lv1～Lv3

- 找一找
- 听一听
- 配一配
- 拖拽
- 点击场景

### Lv4～Lv6

- 词语配对
- 迷宫
- 阅读寻宝
- 情节排序
- 角色任务

### Lv7～Lv10

- 偏旁解谜
- 汉字家族
- 句子重组
- 阅读推理
- 看图表达
- 故事续写

## 9. AI 跟读页

Pad 中央为大麦克风按钮，儿童无需寻找“开始录音”。

状态：

```text
准备 → 倾听 → 说话 → AI识别 → 鼓励反馈 → 下一句
```

反馈优先使用：

- “再读一次，会更清楚！”
- “这个词读得很棒！”
- “我们跟 Bunny 一起再来一次。”

不要用红色叉号、排名、扣分来刺激低龄儿童。

## 10. 学习进阶页

显示四条能力线：

```text
识字  ████████░░
阅读  ██████░░░░
表达  █████░░░░░
书写  ████░░░░░░
```

每条线都可以点击看到下一目标，例如：

```text
阅读能力
当前：能独立读短句
下一步：连续读 3～5 句并回答细节问题
```

## 11. 每日学习计划

AI 根据最近学习记录生成计划，但儿童端只显示 3～5 个任务卡，不展示模型过程。

示例：

1. 热身：复习“山、木、林”。
2. 绘本：读《小兔子找妈妈》3～5 页。
3. 新字：探索“森”。
4. 跟读：读 2 句话。
5. 游戏：森林寻宝。

总预计时长 15～20 分钟。

## 12. 家长中心

家长入口通过长按/密码/家长按钮进入，避免儿童误触。

家长端：

- 学习报告
- 识字掌握趋势
- 阅读记录
- 跟读表现
- 薄弱字词
- 推荐绘本
- 每日时长
- 学习计划调整
- 内容管理
- 麦克风/摄像头/隐私设置

## 13. 反馈设计

### 成功

轻微动画 + 声音 + Bunny 表情 + 星星。

### 失败

提供提示或第二次机会，不打断学习流。

### 连续成功

升级奖励应该以世界成长、绘本解锁、角色装备为主，不把所有奖励做成金币。

## 14. 长期成长

Pad 首页展示世界地图：孩子学习更多汉字后，地图逐渐开放新的区域。

```text
起点岛
 ↓
森林岛
 ↓
故事城
 ↓
汉字博物馆
 ↓
探秘山谷
 ↓
阅读王国
```

世界解锁与能力等级绑定，但允许通过不同活动获得成长，避免单一路径刷题。

## 15. 性能和可访问性

H5 应优先支持：

- 横屏 16:10 / 16:9
- 低功耗设备
- 离线缓存近期绘本与音频
- 资源分级加载
- 大字号
- 高可读对比度
- 网络异常下核心阅读与已缓存游戏仍可继续

动画不应影响按钮点击、文字阅读和语音同步。

## 16. 产品成功标准

不是“孩子做了多少题”，而是：

```text
阅读时长 ↑
绘本完成率 ↑
自主朗读比例 ↑
稳定掌握汉字 ↑
复习后保持率 ↑
主动打开绘本次数 ↑
```
