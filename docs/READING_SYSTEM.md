# Bunny 互动绘本与 AI 陪读系统

## 1. 产品定义

Bunny 的绘本不是音频播放器，而是“可阅读、可点击、可讲解、可跟读、可互动、可理解”的阅读空间。

核心目标：

> Bunny 陪孩子一起读，而不是替孩子把书读完。

## 2. 四种阅读模式

### 2.1 Bunny 讲故事

- Bunny 主讲
- 文字同步高亮
- 角色声音和情绪
- 页面自动/手动切换
- 支持暂停、回听

### 2.2 跟 Bunny 一起读

流程：

```text
Bunny 读一句
 -> 孩子读一句
 -> 检测完成度
 -> 简单鼓励
 -> 下一句
```

目标不是追求发音考试，而是建立“看到字就开口读”的习惯。

### 2.3 孩子自己读

- 打开麦克风
- 识别朗读文本
- 判断句子完成度
- 标记可能漏读/错读片段
- 给一条具体建议
- 支持重新尝试

反馈禁止使用强烈负面表达，如“错误”“失败”。

### 2.4 角色对读

Bunny 和孩子分别扮演角色。

例如：

```text
Bunny: “小兔，你要去哪里？”
Child: “我要去找妈妈。”
```

适合练习：

- 口语
- 朗读
- 情节理解
- 角色表达

## 3. 页面结构

每页推荐包含：

```text
Scene
├── background
├── characters
├── objects
├── text
├── narration
├── interactions
├── targetCharacters
└── nextCondition
```

## 4. 字词互动

绘本内点击字词后，尽量采用“不中断故事”的轻量浮层：

```text
森
sēn
🌲 很多树在一起的地方

[听一遍] [我来读]
```

返回后继续故事，不强制跳离绘本。

## 5. 手指跟读

对于低龄阅读页面，可提供视觉指引：

```text
👆 -> 小 -> 兔 -> 子 -> 在 -> 森 -> 林
```

语音、文字高亮、指示器保持同步。

## 6. 绘本结构

一本书建议包含：

- cover
- opening
- story pages
- interaction pages
- vocabulary moments
- comprehension challenge
- read-again
- completion reward

## 7. 绘本中的新字密度

优先做到：

- 大多数字为已掌握字
- 少量新字
- 新字在上下文中重复出现
- 同一新字在游戏和后续绘本再次出现

## 8. 绘本互动原则

### 好的互动

- 帮角色找到东西
- 选择角色行动
- 改变环境
- 收集物品
- 根据句子完成任务
- 根据故事做推理

### 不推荐

- 阅读过程中突然弹出大量题目
- 每一页都要求选择题
- 连续要求点击正确汉字
- 为了互动而互动

## 9. 内容分层

### 教材课文

重点是准确、同步、朗读和理解。

### 同步原创绘本

围绕课文目标字词做新故事。

### 自由分级绘本

根据 Learner Model 自动推荐。

### 高阶阅读

二年级后逐渐引入更长篇幅、寓言、科普、成语和人物故事。

## 10. 朗读数据

一次阅读会产生：

- bookId
- pageId
- sentenceId
- listenDuration
- readDuration
- completion
- retryCount
- recognizedText
- pronunciationHints
- comprehensionResult

不要把一次朗读分数作为孩子的“固定能力标签”，使用多次行为综合评估。

## 11. 阅读奖励

推荐奖励：

- 解锁下一本书
- 获得角色道具
- 增加世界地图区域
- 完成汉字图鉴
- 解锁新的互动场景

避免只用金币或数字分数驱动。
