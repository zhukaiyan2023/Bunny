# Bunny MVP 与版本路线图

## V0.1 - 可玩原型

目标：证明“绘本 + 陪读 + 识字游戏”闭环成立。

### 内容

- 20-30 个核心汉字
- 3 本原创短绘本
- 4 类小游戏
- 1 个汉字博物馆场景

### 能力

- 绘本播放
- 文本同步高亮
- 点击汉字
- 汉字语音
- 4 种游戏
- 基础奖励

## V0.2 - 人教版一年级同步

目标：形成真实课程价值。

- 建立一年级课程映射
- 100+ 核心汉字
- 10-20 本同步拓展绘本
- 跟读模式
- 基础朗读识别
- 生字复习
- 汉字故事

## V0.3 - AI 个性化

- Learner Model
- 每日学习计划
- 动态绘本推荐
- 动态复习
- 动态游戏难度
- 简单朗读反馈

## V0.4 - 二年级能力升级

- 词语家族
- 阅读理解
- 句子排序
- 寓言/成语故事
- 角色对读
- 更复杂的任务链

## V1.0 - 完整产品

- 1-2 年级完整课程地图
- 大规模绘本库
- 汉字博物馆
- 汉字探秘
- AI 陪读
- 自主阅读
- 家长报告
- 内容管理后台
- 内容 DSL 与自动校验

## MVP 优先级

P0：

- Story Engine
- Game Engine
- Character Model
- Audio Engine
- 基础 Content DSL
- 绘本 3 本
- 4 种游戏

P1：

- 朗读识别
- AI 推荐
- 复习
- 汉字故事
- 教材映射

P2：

- 汉字博物馆完整体系
- 角色养成
- 世界地图
- 家长端
- 大规模内容生成

## 版本判断标准

每个版本必须回答：

1. 孩子愿意继续玩吗？
2. 孩子是否真的读更多了？
3. 汉字是否因为语境重复而更牢？
4. 家长是否能看懂学习进展？
5. 新内容是否不需要大量改程序？
