# Bunny 课程与内容体系

## 1. 课程原则

Bunny 以小学 1-2 年级语文知识体系为主线，采用“教材映射 + 原创分级阅读 + 能力图谱”的三层结构。

人民教育出版社公开目录显示，一年级上册包含“天地人”“金木水火土”“口耳目”“日月水火”“对韵歌”等识字内容，以及《小小的船》《四季》《比尾巴》《乌鸦喝水》等课文和识字表、写字表、常用偏旁等附录。Bunny 使用这些课程结构作为内容规划参考，而不是简单复制教材页面。 citeturn677701search1turn677701search7

## 2. 内容层级

```text
Grade 1
  -> 识字/拼音基础
  -> 词语
  -> 简单句
  -> 课文朗读
  -> 看图表达

Grade 2
  -> 更复杂字词
  -> 句群和短段
  -> 课文理解
  -> 寓言/童话/说明性内容
  -> 初步阅读策略与表达
```

## 4. 内容类型

### A. 教材同步

目标是“今天学校学什么，Bunny 就能提供有趣的第二课堂体验”。

组成：

- 课文导入
- 课文陪读
- 生字卡
- 字源/字形故事
- 词语理解
- 句子理解
- 游戏
- 朗读
- 复习

### B. 同步拓展绘本

围绕教材核心字词重新编写低难度故事，优先复用已经学过的字，仅引入少量新字。

### C. 自由分级绘本

根据儿童 mastery profile 动态推荐。

### D. 汉字知识内容

- 象形字故事
- 会意字故事
- 形声字家族
- 偏旁故事
- 字形演变
- 词语来源
- 成语/典故

### E. 语文能力内容

- 听
- 说
- 读
- 写
- 理解
- 表达

## 5. 分级阅读原则

一本绘本不能只按年龄标级，必须按儿童真实掌握情况标级。

推荐指标：

```text
knownCharacterRatio >= 0.85
newCharacterCount <= 5~8
sentenceLength within current band
rareWordCount low
storyComprehension suitable
```

具体阈值由数据验证后调整。

## 6. 年级阶段设计

### 一年级阶段

重点是“从图和声音进入汉字，再从汉字进入句子”。

游戏以：

- 找一找
- 听一听
- 配一配
- 拖拽
- 场景探索
- 角色互动

为主。

### 二年级阶段

重点转向“从字词进入句段和理解”。

游戏增加：

- 排序
- 推理
- 阅读寻宝
- 角色扮演
- 词语组合
- 句子拼接
- 故事续写
- 阅读理解

## 7. 每个单元的学习节奏

```text
预热
 -> 故事导入
 -> 新字发现
 -> 汉字故事
 -> 词语理解
 -> 跟读
 -> 游戏
 -> 再读
 -> 小挑战
 -> 复习
```

## 8. 不把课程变成刷题

教材同步的正确形态：

> “把课本内容变成孩子必须使用语文能力才能完成的冒险任务。”

例如《乌鸦喝水》可以设计成“帮乌鸦找到小石子并提高水面”的任务，而不是课文后面加 5 道选择题。

## 9. 内容数据来源策略

教材相关事实必须来自合法、受控的教材内容来源和内部授权/合规内容库。公开目录仅用于课程结构核对。

原创绘本、原创旁白、原创游戏和 AI 生成候选内容必须单独记录版权和审核状态。
