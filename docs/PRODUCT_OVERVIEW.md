# Bunny 产品总览

## 1. 产品定位

Bunny 是“会陪孩子读书、讲汉字故事、玩游戏”的中文 AI 学习伙伴。

产品不是传统识字题库，也不是纯绘本播放器，而是一个以互动阅读为入口、以识字与语文能力为核心、以游戏化世界为承载、以 AI 个性化为驱动的 H5 学习系统。

## 2. 核心用户

### 2.1 儿童

- 主年龄：6-8 岁
- 核心阶段：小学 1-2 年级
- 能力特点：具备基础口语能力，逐渐形成识字、朗读、阅读理解和书写能力
- 关键心理：喜欢故事、角色、收集、探索、挑战和即时反馈，不喜欢持续刷题

### 2.2 家长

家长主要关注：

- 是否与学校课程同步
- 孩子是否真的读懂、读会
- 每天学习多久
- 哪些字掌握不牢
- 阅读能力是否持续提高
- 内容是否安全、可靠

## 3. 核心价值主张

> 让孩子因为想知道故事接下来发生什么，而主动认识汉字；让孩子因为认识更多汉字，而能够读更多故事。

形成正循环：

故事兴趣 -> 主动阅读 -> 发现汉字 -> 理解汉字 -> 游戏巩固 -> 再读故事 -> 解锁更丰富阅读 -> 继续探索

## 4. 产品四大世界

### 4.1 故事王国

- 人教/统编教材同步课文
- 原创分级绘本
- 互动故事
- 古诗、寓言、成语故事
- 睡前阅读

### 4.2 汉字博物馆

- 汉字字形
- 拼音
- 汉字来历
- 象形、会意、形声等儿童化解释
- 字形演变动画
- 偏旁和汉字家族
- 词语网络

### 4.3 冒险乐园

- 找字
- 听音选字
- 图文匹配
- 汉字钓鱼
- 汉字寻宝
- 迷宫
- 拼字
- 句子排序
- 阅读解谜

### 4.4 汉字探秘局

- 猜字
- 拆字
- 偏旁侦探
- 字源推理
- 词语搭配
- 成语故事
- 阅读理解挑战

## 5. 核心学习闭环

```text
课程知识
  -> AI 学习诊断
  -> 选择当前学习目标
  -> 互动绘本
  -> 发现新字
  -> 汉字故事
  -> 跟读/自己读
  -> 游戏巩固
  -> 词语/句子理解
  -> 复习
  -> 自由阅读
  -> 解锁新世界
```

## 6. 典型 10 分钟体验

1. Bunny 欢迎，约 20-30 秒。
2. 讲述或共读一本短绘本，约 3 分钟。
3. 识别 3-6 个重点汉字，约 2 分钟。
4. 通过字源/图片/词语小游戏理解，约 2 分钟。
5. 回到绘本朗读，约 1-2 分钟。
6. 获得世界资源或角色奖励，约 30 秒。

## 7. 趣味性原则

趣味来自：

- 目标：孩子想完成一个有意义的事情
- 挑战：难度略高于当前能力
- 探索：不知道下一个内容是什么
- 发现：自己推导出答案
- 收集：字、角色、道具、绘本、场景逐渐完整
- 养成：Bunny 和世界不断成长

禁止把趣味等同于大量烟花、金币、音效和随机弹窗。

## 8. 教材策略

人教/统编版内容作为课程映射底座，不直接把教材页简单搬成 H5。

教材决定：

- 学习目标
- 核心字词
- 课文/口语交际/语文园地等知识结构
- 书写与语文能力要求

Bunny 重新设计：

- 故事情境
- 互动方式
- 游戏机制
- 陪读体验
- 复习路径

## 9. AI 策略

AI 不负责自由改变课程标准，而负责：

- 学习诊断
- 内容推荐
- 难度动态调整
- 陪读反馈
- 个性化复习
- 原创绘本候选生成
- 游戏候选生成

事实型内容，尤其教材映射、字源知识、笔顺、拼音等，必须进入受控知识库。

## 10. 核心成功指标

### 学习指标

- 新字掌握率
- 复习后保持率
- 跟读完成率
- 独立朗读完成率
- 阅读理解正确率
- 自主阅读分钟数

### 产品指标

- 次日/7日回访
- 每周阅读次数
- 每次学习平均时长
- 绘本完成率
- 游戏退出率
- 复习完成率

### 内容指标

- 每本绘本目标字覆盖率
- 已学字占比
- 生字密度
- 游戏与知识目标匹配度
- 内容 QA 通过率
