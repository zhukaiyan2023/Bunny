# Bunny 游戏体系

## 1. 游戏定位

游戏不是独立娱乐模块，而是学习目标的交互实现。

每个游戏必须绑定一个或多个明确学习目标：

- 识字
- 听音
- 字形辨识
- 词义理解
- 词语搭配
- 句子理解
- 阅读理解
- 朗读
- 偏旁识别
- 笔顺/书写

## 2. 基础游戏类型

### G01 找字 FindCharacter

目标：视觉字形识别。

玩法：在多个候选字中找到目标字。

### G02 听音选字 ListenChoose

目标：音 -> 字。

### G03 看图识字 ImageToCharacter

目标：图 -> 字。

### G04 图文配对 Match

目标：图、字、词建立对应关系。

### G05 汉字钓鱼 Fishing

目标：在场景任务里找目标字。

### G06 汉字寻宝 Treasure

目标：探索场景并发现目标字。

### G07 汉字拼拼乐 BuildCharacter

目标：部件观察/组成。

### G08 词语搭配 WordMatch

目标：词义与搭配。

### G09 句子排序 SentenceOrder

目标：语序和句子理解。

### G10 阅读解谜 ReadingPuzzle

目标：根据故事信息解决问题。

### G11 角色扮演 RolePlay

目标：朗读、口语与理解。

### G12 笔顺/描红 Trace

目标：书写与笔顺。

## 3. 难度梯度

### L1 发现

- 少量选项
- 大图片
- 单字
- 高反馈

### L2 识别

- 增加干扰项
- 图文转换
- 声音转换

### L3 应用

- 词语
- 短句
- 组合

### L4 理解

- 句群
- 故事信息
- 多步骤任务

### L5 表达

- 角色扮演
- 复述
- 自主阅读

## 4. 任务链设计

游戏最好嵌入故事任务：

```text
剧情目标
 -> 遇到障碍
 -> 使用汉字/阅读能力解决
 -> 游戏操作
 -> 剧情继续
```

例如《乌鸦喝水》：

```text
发现瓶子
 -> 找石头
 -> 识别“石/子/水”
 -> 点击石头
 -> 瓶中水位上升
 -> 乌鸦喝到水
```

## 5. 反馈机制

成功：

- 轻量动画
- 角色表达
- 世界变化
- 新道具/内容解锁

失败：

- 不扣除大量资源
- 不出现“失败”大字
- 给一个提示
- 允许再次尝试

## 6. 防止游戏变无聊

相同知识目标可以使用不同机制：

```text
猫
-> 找字
-> 钓鱼
-> 森林寻宝
-> 角色对话
-> 绘本点击
-> 词语搭配
```

重复的是知识，变化的是体验。

## 7. 游戏统一输入输出

输入：

- targetKnowledge
- difficulty
- scene
- learnerProfile
- availableCharacters
- storyContext

输出：

- success/failure
- attempts
- reactionTime
- errorType
- targetMasteryUpdate
- reward

## 8. 游戏创作原则

一个游戏开始前必须先写清楚：

> 孩子玩完以后，比玩之前多会什么？

如果答案不明确，该游戏不能进入内容库。
