# Bunny 内容生产与质量规范

## 1. 内容生产流水线

```text
课程规划
 -> 学习目标
 -> 故事/游戏设计
 -> AI 生成候选
 -> 自动检查
 -> 内容编辑审核
 -> 教学审核
 -> 音视频审核
 -> 发布
 -> 数据观察
 -> 迭代
```

## 2. 字源内容 QA

字源是高风险知识模块，必须：

- 标记知识类型
- 标记证据等级
- 与通识文字学资料核对
- 区分“事实”与“儿童化讲法”
- 禁止用不可靠网络故事作为确定历史事实

## 3. 教材内容 QA

每条教材映射至少验证：

- 年级
- 册次
- 单元/课次
- 生字
- 词语
- 课文关联
- 写字要求
- 教材版本

## 4. 绘本 QA

### 教学

- 目标字明确
- 已学字占比合理
- 新字数量受控
- 词语和句子难度匹配
- 故事情节完整

### 阅读

- 文字与语音一致
- 高亮与语音同步
- 点击生字不破坏主线
- 跟读入口明显
- 支持重读

### 儿童体验

- 无恐吓
- 无羞辱
- 无高压倒计时
- 错误后可恢复
- 不依赖复杂文字说明才能开始游戏

## 5. 游戏 QA

每个游戏需要写清楚：

- 学习目标
- 操作方式
- 正确条件
- 错误类型
- 提示
- 成功反馈
- 重新尝试
- 数据事件

## 6. 音频 QA

必须验证：

- 音频存在
- 文本与音频一致
- 音量统一
- 语速适合儿童
- 无明显爆音/底噪
- 角色声音稳定

## 7. AI 输出 QA

自动检查：

- 禁止不存在的汉字知识
- 禁止编造教材信息
- 禁止把创作故事描述为历史事实
- 禁止不适龄内容
- 禁止输出不受控链接
- 禁止事实和意见混淆

## 8. 发布准入

内容同时满足：

```text
Schema PASS
+ Curriculum PASS
+ Learning Objective PASS
+ Linguistic PASS
+ Child Safety PASS
+ Audio/Visual PASS
+ Editorial PASS
```

才可以进入 published。

## 9. 数据回收

上线后观察：

- 跳出点
- 重试次数
- 读完率
- 生字错误率
- 游戏成功率
- 复习成功率
- 家长负反馈

数据用于修改内容难度，不用于给儿童贴固定标签。
