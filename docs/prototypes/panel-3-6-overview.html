01 · 首页

世界地图 / 4 大岛入口

Bunny 在中央说话；4 个大岛屿（故事岛 / 汉字花园 / 玩游戏 / 我的小屋），每个岛显示"本岛 N 字 · 已学 N 字"。顶部"已学 47 / 3000 字"。

02 · 绘本陪读

Bunny 讲故事

大插画 + 当前句子单行大字 + Bunny 大头像。点击字不打断故事，只让 Bunny 重读。右侧大麦克风按钮（≥ 120px）。

03 · 汉字花园

拟人化汉字方块 + 图示

先图后字，不引入字源 / 演变 / 词语。主字卡 ≥ 240px 大字 + 拼音 + Bunny 跟读。标签"🌳 家岛 · 第 2 个字 / 本岛还有 253 字没学"。

04 · 玩游戏

找一找 / 大场景 + 3 个字按钮

单题单屏，3 个大按钮（≥ 160×160）带表情。错误反馈 = "Bunny 没听清，再点一次"。永不显示"正确率"。

05 · 我的小屋

拟人化小屋 + 勋章墙 + 字花园入口

小屋带眼睛 + 烟囱 + 窗户。3×2 勋章网格。3000 字进度条 "47/3000"。两个大按钮："🌳 看字花园全景 / 🗂️ 看收藏册"。

06 · 跟 Bunny 读

大麦克风 + Bunny 鼓励语

屏幕里只 1 个句子 + 1 个 ≥ 200px 麦克风按钮 + Bunny 鼓励条。完全无分数 / 无红叉 / 无扣分。

07 · 字花园全景（3000 字骨架）

10 个主题岛 × 300 字

起步岛（已种满 50）+ 当前家岛（已学 47/300）+ 动物/植物/身体/动作/颜色/自然/数字 + 故事/字家族。每个汉字 = 1 棵苗（已学）/ 1 颗果（掌握）/ 1 颗种（未学）。3-6 岁只看到长出来的那一片。

08 · 字时光机

3 / 6 / 9 / 12 岁四阶段字量目标

启蒙 100 字 → 入学 300 字 → 进阶 1500 字 → 自由阅读 3000 字。让孩子从小知道"读完这一岛还有下一岛，但每次只学一点点"。

设计基线（3-6 岁适龄 × 3000 字架构）

  • 单次体验小 · 3-5 字 / 次，5-10 分钟；不试图一次塞 3000 字。
  • 长期累积显式可见 · 顶部 47/3000 字、字花园 10 岛、时光机 4 阶段 —— 让孩子从小知道"还有好多没种"。
  • 大 Bunny 始终在场 · 圆胖 1.5 头身，白毛 + 粉内耳 + 红书包 + 长垂耳，绝不出现其他动物或竖耳兔。
  • 主 CTA ≥ 120px · 触控目标 ≥ 88px · 不引入 swipe / drag / pinch 等组合手势。
  • 图标为主 · 文字最少 · 屏幕汉字 ≤ 20 个，且 ≤ 2 行。拟人化图标都带圆眼睛 + 腮红。
  • 永不负面反馈 · 错误 = "Bunny 没听清，再点一次"，从不出现红叉、扣分、排名、失败屏。
  • 进度用星 / 用苗 · "找到 5 颗星"、"种下 47 棵苗"，不用百分数 / 等级数字。
  • 3000 字 = 10 岛 × 300 字 · 每个岛一个主题（家 / 动物 / 植物 / 身体 / 动作 / 颜色 / 自然 / 数字 / 故事 / 字家族），让孩子按主题认知汉字。
  • 分级体验而非分级 UI · 3-6 岁和 6-9 岁共享同一个 Bunny 视觉系统，但首页 4 岛 → 字花园 10 岛、字时光机呈现"再大一些的样子"。
  • Bunny 品牌色 · 红 #E94545 · 奶油 #FFF4E6 · 桃 #FFE0BF · 薄荷 #A8E6CF · 黄油 #FFE9A8 · 淡紫 #D9C2F0 · 柔粉 #FFC1CC。
  • 音频优先 · 所有 UI 元素都应有"点一下 Bunny 读给你听"的能力。
