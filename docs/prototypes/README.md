# Bunny H5 原型说明

## 原型目标

这套原型不是纯视觉稿，而是用于统一产品、设计、前端和内容团队对核心交互的理解。核心原则：

> Story-led（故事驱动） + Read-aloud-first（陪读优先） + Character-origin curiosity（汉字来历好奇心） + Game as Mission（游戏作为任务） + AI Personalization（个性化学习）

## 核心页面

| 页面 | 核心目的 | 主要交互 |
|---|---|---|
| Bunny 世界首页 | 建立儿童世界观 | 故事王国 / 汉字博物馆 / 冒险乐园 / 汉字探秘局 |
| 绘本陪读 | 让 Bunny 带孩子读 | Bunny 讲、一起读、角色对读、点字 |
| 汉字故事 | 让孩子知道字为什么这样写 | 字音、字形、字源故事、演变、发现任务 |
| 汉字游戏 | 用任务驱动识字 | 找字、场景探索、图字匹配、即时反馈 |
| AI 跟读 | 让孩子自己读 | 录音、语音识别、流利度/完整度/发音反馈 |
| 学习报告 | 让成长可见 | 掌握率、新字、绘本、跟读与复习趋势 |

## 交互基线

### 1. 绘本陪读

- 默认由 Bunny 讲故事。
- 支持逐句高亮。
- 支持“一起读”，采用 Bunny 先读、孩子跟读、继续下一句。
- 点击生字后只做短解释，不阻断故事主流程。
- 支持孩子自己读和角色对读。

### 2. 汉字故事

- 内容优先采用可靠的文字学资料。
- “事实”与“儿童化故事”必须分层标记。
- 象形字优先展示“真实事物 → 古人图画 → 古文字 → 今天的字”。
- 会意字优先展示“部件组合 → 意义”。
- 形声字优先展示“偏旁/声旁 → 汉字家族”。
- 不把复杂文字学术语强行塞给低龄儿童。

### 3. 游戏

游戏必须服务学习目标，避免“为了动画而动画”。推荐循环：

```text
目标 → 尝试 → 发现 → 成功 → 奖励 → 新问题
```

### 4. AI 跟读

反馈应该鼓励孩子继续阅读，不采用考试式红叉反馈。推荐：

- “你读得很棒！”
- “再试一次‘森林’。”
- “这一句已经很流利了。”

## 设计方向

- 低龄儿童：大按钮、少文字、明显反馈、连续动画。
- 画面：自然、温暖、明亮，不做过度刺激的卡通堆叠。
- Bunny 是陪伴角色，不是老师讲台上的老师。
- 所有核心学习动作都尽可能有“故事上下文”。

## 教材映射

Bunny 以人教版/统编版 1–2 年级语文作为课程结构参考，覆盖识字、拼音、阅读、口语表达、语文园地及分级阅读拓展。人民教育出版社公开目录可核对一年级上、一下和二年级上、下的课程结构。实际产品上线前应以项目获得授权的具体教材版本和内容库为准，不直接复制教材正文或插图。

## 开发顺序

1. 先实现绘本陪读 Engine。
2. 再实现 Character Detail / Character Story Engine。
3. 再接通 Game Engine。
4. 再接 AI Learner / 推荐与复习。
5. 最后扩展家长报告与内容生产后台。
