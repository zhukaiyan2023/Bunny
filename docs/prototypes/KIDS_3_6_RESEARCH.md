# Bunny · 3-6 岁儿童产品 UX 调研与适配分析

> 调研目的：把 Bunny 平台从原定 **6-8 岁 / 小学 1-2 年级** 主用户，下沉到 **3-6 岁 / 学前与一年级入门** 时的视觉、交互、内容、认知负荷的差距，并给出可落地的原型设计基线。

## 1. 3-6 岁用户画像（儿童端）

| 维度 | 3-4 岁 | 5-6 岁 |
|---|---|---|
| 识字 | 0-50 字，主要靠图 | 100-300 字，开始识常用字 |
| 阅读 | 看图说话、复述 | 跟读单句、读 3-5 句短文 |
| 手部精细动作 | 仍不稳定，触控漂移 | 可点 / 拖 / 简单书写 |
| 注意力 | 3-5 分钟一轮 | 8-12 分钟一轮 |
| 情绪 | 强烈依赖安抚、鼓励、不喜欢失败 | 喜欢角色、收集、故事 |
| 父母参与 | 必须有父母协助操作 | 可独立操作，但需要家长看护 |

**关键约束**

- 不会拼音声调系统，**拼音辅助** 在这个年龄段不是默认主路径。
- 看不懂长句，**图标 > 文字** 是首要信息载体。
- **不允许失败感**：任何"答错"必须用鼓励式提示（再试一次）而不是红叉、扣分、排名。

## 2. 行业最佳实践（结合 Nielsen、NN/g、Common Sense Media 儿童 UX 框架）

### 2.1 视觉

- **色彩饱和度更高**：饱和的暖色（红、橙、黄）抓注意；冷色（蓝、绿、紫）作辅。
- **主体大、留白多**：单个学习任务占屏 50%+。
- **拟人化角色**：物体带脸（按钮、奖励、汉字卡）。
- **圆润、无尖角**：圆角 18-28px；不要细线条、小字号。
- **自然手绘 / picture-book 风格**：避开商业感强的金属/玻璃拟物。

### 2.2 交互

- **触控目标 ≥ 88px**（高于 Bunny 默认 56px 的上限，接近 Apple iOS 7+ 推荐高值）。
- **每屏 1 个主任务 + 1 个辅助**；**最多 2-3 个可点击元素**。
- **音频优先**：所有 UI 元素都应有"点一下读出来"的能力。
- **手势简化**：只用 tap；不引入 swipe / drag / pinch 等组合手势。
- **可逆、可退出**：随时可回主屏，永远有"Bunny 在这里"。

### 2.3 内容

- **故事化包装**：把"识字"包装成"帮 Bunny 找回家的字"。
- **5-10 分钟一关**：拆成 3-5 个微环节。
- **首屏主任务用图**：把"开始今日冒险"做成大按钮 + Bunny 头像。
- **零文本也能走通**：哪怕一个字也不认识也能点出声音。

### 2.4 反馈与情感

- **永不负面**：没有"错误"、"失败"、"再来一次 + 减分"。
- **正向反馈节奏**：每次成功反馈 0.3-0.5s 出现，连续成功后升级到撒星、世界动画。
- **家长区物理隔离**：长按 + 滑块确认，绝不误触进家长模式。

## 3. Bunny 当前风格差距分析

参考 [`docs/STYLE_GUIDE.md`](../../STYLE_GUIDE.md) 与现有 7 个原型资产（panel-05/07/08/10/12 + bunny-ui-overview + pad-progress-overview），下面列出 3-6 岁视角下的具体差异：

| 维度 | Bunny 当前（6-9 岁） | 3-6 岁建议 | 影响 |
|---|---|---|---|
| 主色饱和度 | 奶油 + 桃 + 薄荷，**柔和、低饱和** | 强化主色饱和，加亮黄/亮红/亮蓝点缀 | 弱吸引 |
| 触控目标 | ≥ 56px | **≥ 88px**，主 CTA ≥ 120px | 易误触 |
| 文案密度 | 主屏 4-6 行字 | 主屏 ≤ 2 行字 + 大图 | 不识字 |
| 图标占比 | 中等（24-48px emoji） | **≥ 80px**，拟人化（带表情） | 不吸引 |
| 角色形象 | 头像圈出现 | **Bunny 角色全程在场景中**，大尺寸站立 | 缺陪伴 |
| 绘本主路径 | 文字高亮 + 4 种阅读模式 | **默认 Bunny 讲**，点击字不弹出解释卡（避免打断） | 中断流 |
| 汉字学习 | 字形 + 字源 + 演变 + 词语 | **图 → 字 1 步**，先图后字，避免字源 | 过载 |
| 游戏 | 找字、听音、迷宫（Lv1-3） | 只保留 **找字 + 看图选字 + 拖拽配对**，3 步内完成 | 太复杂 |
| 跟读 | 流利度 / 完整度 / 发音三维评分 | **只一个鼓励评语 + Bunny 表情**，不显示分数 | 焦虑 |
| 进度信息 | "已掌握 186 字" | **改为视觉进度**："找到 5 颗星，下一关是第 6 颗" | 太抽象 |
| 排行榜 / 等级 | Lv.6 故事探险家（数字等级） | **改成探索路径**："你已经走过 3 个岛屿" | 不友好 |
| 失败反馈 | 引导再试 | **隐藏"错"的概念**：错答变成"Bunny 没听清，再大声一点" | 负向 |

## 4. 3-6 岁适配的设计原则（Bunny 版本）

下面这一组原则将被新的原型集贯彻：

### 4.1 视觉风格 — "Bunny 早教绘本世界"

1. **背景**：保留奶油底（`#FFF4E6`）但**强化 Bunny 主红 `#E94545` 与亮黄 `#FFD15C`** 作为视觉锚。
2. **大色块**：每个屏幕最多 3 个色块 + 1 个主 CTA。
3. **大 Bunny**：Bunny 形象**至少 1/4 屏高**，始终露出全身 + 长垂耳 + 红书包 + 表情。
4. **拟人化 UI**：所有按钮、奖励卡、汉字方块都带圆眼睛 + 笑脸。
5. **零小字**：屏幕里 ≤ 20 个汉字，且 ≤ 2 行。

### 4.2 触控与交互

1. 主 CTA ≥ 120px × 120px，视觉上像是"一个小岛"。
2. 单一手势：tap。
3. 全程有 Bunny 配音（点 Bunny 头就有反馈）。
4. 错误 = Bunny 再说一遍 + 把字变大。

### 4.3 内容节奏

1. 每个场景 5-7 分钟，自然结束。
2. 主页固定 4 个大岛入口：**故事岛 / 汉字花园 / 玩游戏 / 我的小屋**。
3. 进度用 **"找到几颗星"** 而不是百分数。

### 4.4 反馈系统

1. 点中目标 → Bunny 跳一下 + 撒 5 颗星 + 主角动作。
2. 没点中 → Bunny 摇耳朵 + 字卡轻轻晃动 + 再念一遍。
3. 关卡完成 → 大门打开 → 进入下一关，画面右滑 1 段（约 320px 横向移动）。

## 6. 与现有 6-9 岁版本的关系

- 现有 6-9 岁版（`panel-05/07/08/10/12 + bunny-ui-overview + pad-progress-overview`）保留作为**主线版本**，针对小学 1-2 年级 + AI 跟读维度。
- 新增 6 个 3-6 岁原型作为**低龄分支入口**，与主线共享：
  - 同样的色板（`#E94545 / #FFE9A8 / #A8E6CF / #B5DEFF / #FFC1CC / #D9C2F0`）
  - 同样的 Bunny 角色规范
  - 同样的事件埋点（`SESSION_START / CHARACTER_EXPOSED / READ_RESULT`）
  - 不同的导航层级与节奏（更少、更慢、更图形化）

---

**结论**：3-6 岁适配不是"把现有 UI 调大字号"那么简单，而需要一套**低龄专属**的视觉与交互语言。本次 6 屏原型就是把这种语言落到 Bunny 视觉体系里的第一次完整尝试。

## 7. 3000 字架构与 3-6 岁体验的衔接（v2 增补）

> 这一节回答一个核心张力：**3-6 岁单次只能学 3-5 字，但 Bunny 长期目标是 3000 字。**
> 如果不显式建模长期骨架，孩子和家长都会"看不到远方"，容易失去耐心。

### 7.1 3000 字 = 10 主题岛 × 300 字

| 岛 | 主题 | 字数 | 适龄起点 |
|---|---|---|---|
| 1 | 起步（高频字、虚词、量词） | 50 | 3 岁 |
| 2 | 家（家人、家具、房间） | 300 | 3-4 岁 |
| 3 | 动物（哺乳、鸟类、鱼类、昆虫） | 300 | 4 岁 |
| 4 | 植物（花、树、果、菜） | 300 | 4 岁 |
| 5 | 身体（五官、四肢、器官） | 300 | 5 岁 |
| 6 | 动作（走、跑、跳、看、听、说） | 300 | 5 岁 |
| 7 | 颜色 / 形状 | 300 | 5 岁 |
| 8 | 自然（天、地、山、水、天气） | 300 | 6 岁 |
| 9 | 数字 / 时间 / 顺序 | 300 | 6 岁 |
| 10 | 故事 / 汉字家族（偏旁 / 部首） | 600 | 6-12 岁 |

总计 = 50 + 9 × 300 + 600 = **3350 字（≈ 3000 字目标 ± 10%）**。

每个汉字 = 一个学习节点，跨绘本 / 游戏 / 跟读 / 字源 / 复习多模态出现，与 [`MASTER_PLAN.md`](../../MASTER_PLAN.md) 的 9 + 1 维度学习节点模型一致。

### 7.2 单次体验 vs 长期骨架的对应关系

| 单次（3-5 字 / 5-10 分钟） | 长期（3000 字 / 9 年） |
|---|---|
| 今天学了「山、木、水」 | 「家岛」已种 47 / 300 棵苗 |
| 找到了 5 颗星 | 找到 5 颗星就能解锁彩虹徽章 |
| 故事《小兔子找妈妈》 | 「故事岛」共 50 本，已读 12 本 |
| 这一个字我不认识 | 「家岛」还有 253 字没学，继续加油 |

### 7.3 两个新增的 3000 字骨架屏

#### panel-3-6-07 字花园全景

- 一张大海 + 10 个小岛的世界地图；
- 起步岛已"种满"（50 颗红果）；
- 当前岛（家岛）显示 47 棵苗 + 13 颗种子；
- 其他 8 个岛用半透明 + 灰色种子表达"还没到"；
- 底部进度条显式展示 47/3000 字、下一目标；
- 拟物化：每棵苗 = 1 个学过的字、每朵花 = 熟练、每颗果 = 掌握、每颗种子 = 未学。

#### panel-3-6-08 字时光机

- 4 个年龄段卡片（3 / 6 / 9 / 12 岁）分别对应：
  - 3 岁启蒙 · 100 字（大 Bunny + 图→字，本原型）
  - 6 岁入学 · 300 字（教材同步 + 字源，主线原型）
  - 9 岁进阶 · 1500 字（偏旁 + 汉字家族 + 阅读）
  - 12 岁自由 · 3000 字（原创故事 + 文化阅读）
- 一条横轴时间线，把 4 个阶段串成"一步一步走"；
- 让孩子从小知道"读完这一岛还有下一岛，但每次只学一点点"；
- 父母端可以单独查看"3 年后能读 300 字，9 年后能读 3000 字"的预期。

### 7.4 与 6-9 岁版的关系（不是替代，是分支）

| | 3-6 岁分支（新增） | 6-9 岁主线（已有） |
|---|---|---|
| 目标 | 让幼儿"玩中学 + 知道远方" | 让小学生"系统学 + 跟读评分" |
| 单次 | 3-5 字 + 1 故事 + 1 游戏 | 5-8 字 + 1 绘本 + 跟读 |
| UI 触控 | ≥ 88 px | ≥ 56 px |
| 主屏汉字 | ≤ 20 个 | 50-100 个 |
| 进度展示 | "种下 47 棵苗" | Lv.6 / 进度条 |
| 跟读反馈 | Bunny 鼓励短句 | 流利度 / 完整度 / 发音 |
| 入口 | 字花园 10 岛 + 字时光机 | 课程表 / 等级页 / 报告页 |

两条分支在 6 岁时合流：3-6 岁版的"家岛 300 字"自然衔接 6-9 岁版的"小学 1 年级 300 字"。

### 7.5 实现要点（给前端 + 内容 + AI 团队）

1. **每个汉字至少绑定 1 个主题岛**（不能"无家可归"）。`tools/cue-manifest.mjs` 增加 `--island <name>` 必填校验。
2. **AI 推荐下一字**时，按"当前岛 → 下一岛 → 字族复习"的顺序，而不是随机 5 字。
3. **进度事件埋点**：`CHARACTER_EXPOSED` 时记录所属岛屿；`CHARACTER_MASTERED` 时把状态从 sprout → bloom → fruit；面板 07 / 08 直接消费这些事件。
4. **长期回顾任务**：每周从"已学但未熟练"的字里挑 5 字做游戏（用 panel-04 类型）。
5. **家长区视图**直接复用面板 08（字时光机），但叠加"距下一里程碑还差几天"的推算。

---

**结论 v2**：3-6 岁适配 + 3000 字长期目标不是冲突的，关键是：
**单次体验小 + 长期累积显式可见**。
本次新增的 8 个 3-6 岁原型 + 2 个 3000 字骨架屏（字花园 / 字时光机），把这条主线完整落地。
