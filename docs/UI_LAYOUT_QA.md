# Bunny UI / Image QA 标准

## 1. 根因

旧版的问题主要来自三类：固定画布导致 Pad 裁切；AI 整张 UI / 插画把文字、汉字和视觉混在一起；一级导航同时存在顶部返回和底部导航，造成重复导航。

## 2. Pad 全局布局规则

- 设计基准：Pad 横屏 1366×1024。
- 运行时容器必须可收缩，不允许核心内容依赖不可收缩的固定列。
- BottomNav 是一级导航；有 BottomNav 的一级页面默认**不显示顶部返回按钮**。
- 顶部只负责页面标题、学习进度和上下文信息。
- 页面内容必须为 BottomNav 预留安全区；禁止被底栏覆盖。
- 900px 以下进入窄屏降级布局。
- 一级入口：首页 / 故事 / 汉字 / 今日 / 游戏 / 小屋。
- “冒险乐园”是首页入口指向的地图型学习世界；“游戏”导航进入具体小游戏。

## 3. 汉字图片规则

**汉字本体永远是第一视觉元素。**

目标权重：

```text
汉字本体      60%～70%
对应实物/场景 20%～30%
装饰           ≤10%
```

例如：

- 山：先看到大号“山”，辅助出现真实山峰。
- 水：先看到大号“水”，辅助出现明确流动的水。
- 木：先看到大号“木”，辅助出现树木结构。
- 日：先看到大号“日”，辅助出现太阳。
- 月：先看到大号“月”，辅助出现弯月。

不能出现“图片看起来像某个东西，但和目标字无法对应”的情况。

第一阶段采用 `assets/art/l1/teaching/teach-*.svg` 作为确定性教学资产；图片中的汉字不交给生成模型猜，而由 SVG/前端明确渲染。

## 4. 图片生成规则

- 图片只负责视觉，不负责中文标题、按钮、说明、汉字教学文字和 UI 数字。
- AI 生图必须按单一语义目标验收。
- 需要兔子，就必须一眼识别为兔子；需要山、水、木、日，就必须一眼识别对应对象。
- 角色外观必须保持一致：Bunny = 白色长耳兔 + 粉色内耳 + 圆眼 + 红色书包。
- 绘本不能只展示渐变背景或 emoji；每一页必须有实际插画资产或明确的环境/场景资产。
- 不能使用一张语义不匹配的图充当多个不同对象。

## 5. 绘本规则

绘本页面必须形成：

```text
对应插画
   ↓
句子
   ↓
逐字点击
   ↓
Bunny 讲读
   ↓
跟读
```

当前仓库已有三本绘本封面：

- `cover-xiao-tu-de-jia.jpg`
- `cover-tai-yang-he-yue-liang.jpg`
- `cover-sen-lin-li-de-yi-tian.jpg`

在逐页插画尚未全部完成前，页面先使用“绘本封面 + 对应环境背景”保证内容不是空白占位；后续逐页插画应替换成真正 page-level asset。

## 6. 冒险乐园规则

冒险乐园不是普通的 10 张圆卡片列表，而是“地图型学习路径”：

```text
Bunny 起点
   ↓
起步森林 → 温暖小屋 → 动物谷 → 树木岛 → … → 故事城堡
```

要求：

- 10 个站点沿地图区域组织，不再做硬塞在卡片里的普通后台网格。
- 每个站点显示序号、主题、字数、掌握进度。
- 锁定站点保持低对比度，但仍能看见未来目标。
- 地图背景必须是实际场景图片。
- 点击站点进入对应学习内容。

## 7. QA 清单

- [ ] iPad Pro 1366×1024
- [ ] 1280×960
- [ ] 1024×768
- [ ] 浏览器 100% / 80% / 50%
- [ ] 无横向滚动
- [ ] BottomNav 不遮内容
- [ ] 一级页面无重复返回按钮
- [ ] 汉字是汉字页第一视觉元素
- [ ] 山 / 水 / 木 / 日 / 月 与图片语义一致
- [ ] 绘本有实际插画
- [ ] 图片无乱码、假 UI、错误汉字
- [ ] 图片不变形、不裁切主体
- [ ] 触控目标 ≥56px
