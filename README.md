# Bunny

Bunny 是一个面向小学 1-2 年级儿童的中文 AI 阅读与识字产品。

核心理念：

> 以统编/人教版小学语文知识体系为课程底座，以互动绘本为学习主线，以汉字来历与故事增强记忆，以游戏推动探索，以 AI 陪读和个性化学习形成长期阅读能力。

## 开发原则

1. 绘本是主线，游戏是学习机制，不把产品做成刷题工具。
2. 教材知识决定“学什么”，AI 决定“现在学什么”，故事决定“为什么学”，游戏决定“怎么学”。
3. 同一个汉字必须跨图片、声音、字源故事、词语、绘本、游戏和复习反复出现。
4. 内容配置驱动，游戏运行时驱动，禁止一个游戏一个硬编码页面。
5. AI 可以生成候选内容，但教材映射、字源事实和发布内容必须经过结构化校验。
6. 儿童产品优先保证低认知负荷、即时反馈、可恢复、可探索和正向鼓励。

## 当前产品边界

- 首发年龄：6-8 岁为主，兼顾一年级下至二年级儿童。
- 首发课程：人教/统编版小学语文 1-2 年级核心内容映射。
- 首发形态：H5，优先移动端，同时支持平板和桌面浏览器。
- 首发目标：建立“课程 -> 汉字 -> 绘本 -> 陪读 -> 游戏 -> 复习”的完整闭环。
